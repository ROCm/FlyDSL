# M13 native A8W4 EP8 acceptance baseline (MI355X)

Validated 2026-08-27 on eight MI355X GPUs. The production contract is M13
`D=3584, I=1280, E=384, EP=8, topk=8`, with `tokens=MTPR` in
`1,4,8,16,32,64,128,256,512`. MTPR 1024 is intentionally rejected by the
current decode contract.

The gate uses 20 CUDAGraph replays after ten warmups and compares the maximum
latency across all eight ranks. Accuracy uses the dequantized-weight oracle;
graph replay output must have relative L2 below `1e-6`. Performance must be no
more than 5% above the committed rank-max baseline.

| tokens | relL2 max | Stage1 max (us) | Stage2 max (us) | BF16 E2E max (us) | baseline (us) |
|---:|---:|---:|---:|---:|---:|
| 1 | 0.04918 | 40.6 | 17.2 | 64.4 | 65.3 |
| 4 | 0.04782 | 69.6 | 22.4 | 96.4 | 97.8 |
| 8 | 0.04769 | 75.6 | 30.2 | 111.7 | 109.3 |
| 16 | 0.04712 | 100.6 | 33.5 | 137.7 | 137.0 |
| 32 | 0.04693 | 94.6 | 34.0 | 134.0 | 131.6 |
| 64 | 0.04690 | 99.3 | 36.8 | 138.8 | 137.3 |
| 128 | 0.04683 | 93.2 | 46.9 | 147.2 | 141.2 |
| 256 | 0.04677 | 139.6 | 73.0 | 212.1 | 210.0 |
| 512 | 0.04669 | 227.4 | 109.3 | 335.0 | 329.9 |

The t1/t4 rows use a 256-CTA resident role grid with retired control roles and
static consumer work (D128/D96 respectively); t128 uses the validated
TN256/W8/gm2/D224/dg8 winner. Every production point passed in a separate
eight-rank process with `graphReplayRelL2max=0`,
zero strict failures, and its committed 5% performance gate. Raw logs are in
`/home/ghu/opus_verify_47/results/mx_bfr1_official_pytest_acceptance_20260827`
on the validation host. Separate processes are intentional: native decode's
contract requires `tokens=MTPR`, hence each point represents a different
operator instance and symmetric-workspace configuration.

Reproduce from a built FlyDSL environment:

```bash
MEGAMOE_M13_A8W4_CI_ITERS=10 \
pytest -s -q \
  tests/kernels/test_mega_moe_int8.py::test_m13_native_a8w4_8gpu_acceptance
```
