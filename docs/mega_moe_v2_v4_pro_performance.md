# MegaMoEV2 v4_pro Performance

Test configuration: 8× MI355X, `v4_pro`, A8W4, CUDAGraph replay. BS1–128 use the final two-group
fixed-slot overlap configuration; BS256–2048 use compact. These refreshed rows use 100 iterations,
while the remaining rows use 50 iterations. `Speedup = V1 threshold / complete BF16-input E2E`;
values above 1× are faster. BS256 and BS1024 V1 thresholds are filled from the slower MegaMoEV1
measurements in `hgl_v2.log` and `hgl_v3.log`.
