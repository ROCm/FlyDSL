Source-tree kernel library
==========================

The repository's ``kernels/`` tree is not installed by the ``flydsl`` wheel
and is not part of the stable Python API. Its architecture- and model-specific
interfaces change as implementation and tuning work evolves, so this API page
no longer catalogs individual entry points.

Use :doc:`../prebuilt_kernels_guide` for the source-tree workflow and the
matching files under ``tests/kernels/`` as executable examples for the exact
revision you are using.
